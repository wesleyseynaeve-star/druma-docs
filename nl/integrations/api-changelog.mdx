Wijzigingen binnen v1 zijn additief. Brekende wijzigingen en uitfaseringen staan hier als eerste. Het beleid staat onder [API-versiebeheer](/nl/integrations/api-versioning).

## 2026-10-10

**Toegevoegd (v1, geen actie nodig)**

- **Versieheaders.** Elke respons van de Public API, de Finance API en de inkomende Client API bevat `Druma-Api-Version: 1`. U kunt hem ook in verzoeken meesturen.
- **`/v1/`-paden.** `/public-api/v1/orders` en `/finance-api/v1/billable` werken nu. Bestaande paden zonder versie zijn ongewijzigd en betekenen v1.
- **Webhook `event_id` en `api_version`.** Elke webhook-body krijgt deze twee velden. `event_id` blijft gelijk bij herhalingen, gebruik hem om te ontdubbelen.
- **Webhookheaders.** `X-Druma-Event-Id`, `X-Druma-Event-Type`, `X-Druma-Timestamp` en `Druma-Api-Version` bij elke levering.
- **Handtekening met tijdstempel.** HMAC-leveringen voegen `X-Druma-Signature-V2: t=<unix>,v1=<hex>` toe tegen replay. `X-Druma-Signature` is ongewijzigd.
- **OpenAPI 3.1-referentie** voor de Public API en de Finance API.

**Uitgefaseerd / verwijderd:** niets.
