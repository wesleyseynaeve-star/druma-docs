Verejné API Druma poskytuje **prístup len na čítanie** (REST) k vašim zákazkám — vhodné pre samoobslužný portál klientov, BI/reportovací nástroj alebo interné nástroje.

---

## API kľúče a rozsahy

Administrátori firmy vydávajú vlastné kľúče v **Nastavenia → Integrácie → API kľúče** — kliknite na **Vytvoriť kľúč**, pomenujte ho a vyberte rozsah:

| Rozsah | Čo poskytuje |
|---|---|
| **Operator (plný prístup na čítanie)** | Koncové body len na čítanie z tejto stránky, pre vašu firmu |
| **Finance (export na fakturáciu + import faktúr)** | Iba [Finance API](/sk/integrations/finance-api) |
| **Accountant (čítanie viacerých firiem)** | Prístup na čítanie k firmám, pre ktoré bol kľúč vydaný |

<Warning>
Úplný kľúč sa zobrazí **len raz**, pri vytvorení. Druma ukladá iba hash, takže ho nemôže zobraziť znova — skopírujte si ho hneď. Ak ho stratíte, zrušte kľúč a vydajte nový.
</Warning>

Rozsah nie je odporúčanie: volanie koncového bodu Finance API kľúčom Operator vráti `403` — a naopak.

## Autentifikácia

Všetky požiadavky musia obsahovať váš API kľúč v hlavičke `X-API-Key`:

```
X-API-Key: YOUR_API_KEY
```

Požiadavky bez platného kľúča vrátia `401 Unauthorized`. Autentifikácia tokenom Bearer (`Authorization: Bearer ...`) **nie je** podporovaná a tiež vráti 401.

Základná URL: `https://iyegqyqnihupmhmrxfnx.supabase.co/functions/v1/public-api`

## Dostupné endpointy

Verejné API je len na čítanie — akceptujú sa iba požiadavky `GET`. Všetky odpovede sú JSON.

| Metóda | Endpoint | Popis |
|---|---|---|
| `GET` | `/orders` | Zoznam zákaziek (stránkovaný, voliteľný filter `status`) |
| `GET` | `/orders/{id}` | Detail zákazky |
| `GET` | `/orders/{id}/location` | Aktuálna poloha nákladiaka a posledné ETA |
| `GET` | `/orders/{id}/documents` | Dokumenty s podpísanými URL na stiahnutie |
| `GET` | `/pallet-balances` | Paletová pozícia podľa klienta a dopravcu (iba kľúče Operator) |
| `GET` | `/pallet-movements` | Paletový register, stránkovaný (iba kľúče Operator) |
| `GET` | `/pallet-vouchers/{id}` | Podpísaný paletový poukaz (iba kľúče Operator) |
| `GET` | `/jpk-v7m` | Poľské DPH záznamy za jeden mesiac ako XML súbor |

Každý iný zdroj alebo metóda iná ako GET vráti chybu `404`/`405`. Stránkovanie používa `?page=` a `?limit=` (max. 100).

Toto API je **v1**: cesty fungujú aj ako `/public-api/v1/...` a každá odpoveď obsahuje hlavičku `Druma-Api-Version`. Nové polia sa môžu objaviť kedykoľvek, ignorujte preto polia, ktoré nepoznáte. Pozri [Verzovanie API](/sk/integrations/api-versioning). Úplná referencia OpenAPI je v navigácii v skupine **API reference**.

## Limity požiadaviek

- **100 požiadaviek za minútu** na API kľúč
- Ak limit prekročíte, dostanete `429 Too Many Requests` s hlavičkou `Retry-After`, ktorá udáva, koľko sekúnd počkať

Pre vyššie limity napíšte na support@druma.io.
