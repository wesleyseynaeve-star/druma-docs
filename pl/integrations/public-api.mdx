Publiczne API Druma daje **tylko-do-odczytu** dostęp REST do Twoich zleceń — przydatne dla portalu samoobsługowego klienta, narzędzia BI/raportowego lub wewnętrznych narzędzi zbudowanych przez Twój zespół.

---

## Klucze API i zakresy

Administratorzy firmy wydają własne klucze w **Ustawienia → Integracje → Klucze API** — kliknij **Utwórz klucz**, nadaj mu nazwę (na przykład `Eksport QuickBooks`) i wybierz zakres:

| Zakres | Co daje |
|---|---|
| **Operator (pełny dostęp do odczytu)** | Punkty końcowe tylko do odczytu z tej strony, dla własnej firmy |
| **Finance (eksport do fakturowania + import faktur)** | Wyłącznie [Finance API](/pl/integrations/finance-api) — pobieranie zleceń do zafakturowania i odsyłanie wystawionych faktur |
| **Accountant (odczyt wielu firm)** | Dostęp do odczytu dla firm, dla których klucz został wydany |

<Warning>
Pełny klucz jest pokazywany **tylko raz**, w chwili utworzenia. Druma przechowuje wyłącznie skrót, więc nigdy nie pokaże go ponownie — skopiuj go od razu do systemu docelowego. Jeśli go zgubisz, unieważnij klucz i wydaj nowy.
</Warning>

Istniejące klucze pokazują swój zakres, prefiks klucza oraz datę ostatniego użycia (albo **nigdy**). **Unieważnij** natychmiast wycofuje klucz z użycia — każdy system, który wciąż go używa, od razu przestaje działać, więc sprawdź *Ostatnio użyty*, zanim unieważnisz klucz, którego sam nie wydałeś.

Zakres nie jest sugestią: wywołanie punktu końcowego Finance API kluczem Operator kończy się błędem `403` — i odwrotnie.

## Uwierzytelnianie

Wszystkie żądania API muszą zawierać Twój klucz API w nagłówku `X-API-Key`:

```
X-API-Key: TWÓJ_KLUCZ_API
```

Żądania bez ważnego klucza zwracają odpowiedź `401 Unauthorized`. Uwierzytelnianie tokenem Bearer (`Authorization: Bearer ...`) **nie** jest obsługiwane i również zwraca 401.

## Dostępne endpointy

Publiczne API jest tylko do odczytu — akceptowane są wyłącznie żądania `GET`. Wszystkie odpowiedzi są w formacie JSON. (Zapis z powrotem do Drumy to zadanie [Finance API](/pl/integrations/finance-api), na osobnym kluczu.)

| Metoda | Endpoint | Opis |
|---|---|---|
| `GET` | `/orders` | Lista zleceń (paginowana, opcjonalny filtr `status`) |
| `GET` | `/orders/{id}` | Szczegóły zlecenia |
| `GET` | `/orders/{id}/location` | Bieżąca pozycja ciężarówki i najnowsze ETA |
| `GET` | `/orders/{id}/documents` | Lista dokumentów z podpisanymi URL-ami do pobrania, ograniczonymi czasowo |

Każdy inny zasób lub dowolna metoda inna niż GET zwraca błąd `404`/`405`.

## Limity zapytań

- **100 żądań na minutę** per klucz API
- Jeśli przekroczysz limit, otrzymasz odpowiedź `429 Too Many Requests` z nagłówkiem `Retry-After` informującym, ile sekund odczekać
- Nie są zwracane żadne inne nagłówki limitu zapytań

W celu uzyskania wyższych limitów skontaktuj się z support@druma.io, podając swój przypadek użycia.
