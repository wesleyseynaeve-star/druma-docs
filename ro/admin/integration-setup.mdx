Toate integrările companiei tale se configurează într-un singur loc: **Setări → Integrări**. Nu ai nevoie de un dezvoltator — fiecare configurare se face printr-un formular, în mai puțin de cinci minute.

## Găsirea unei integrări

Pagina de Integrări grupează fiecare card în categorii — GPS/Telematică, Reefer/Temperatură Remorcă, Conformitate, eCMR, Marfă, Date de Piață, Contabilitate, Mesagerie și Platformă. Un rând de **pastile de categorie** din partea de sus a paginii îți permite să filtrezi la o singură categorie (fiecare pastilă arată câte integrări conține); apasă **Toate** ca să vezi din nou totul. O **căsuță de căutare** lângă pastile filtrează cardurile după nume sau descriere pe măsură ce tastezi — utilă odată ce compania ta are mai multe integrări configurate și vrei doar să sari direct la una.

## 1. Furnizor eCMR

Druma emite scrisori de transport electronice **intern, folosind furnizorul nativ Druma** — fără cont extern, cheie API sau configurare necesară. eCMR este disponibil din start pentru comenzile transfrontaliere, iar Druma sigilează fiecare document finalizat cu o semnătură digitală PAdES.

Cardul furnizorului eCMR are doar două stări posibile: **Nativ** și **Dezactivat**. TransFollow nu este o opțiune selectabilă — există doar ca rută moștenită pentru un număr mic de companii cu o configurare preexistentă (vezi nota de mai jos).

<Steps>
  <Step title="Deschide cardul Furnizor eCMR">
    Mergi la **Setări → Integrări** și deschide cardul **Furnizor eCMR**. **Nativ** este selectat implicit.
  </Step>
  <Step title="Testează conexiunea">
    Apasă **Testează Conexiunea**. Druma verifică că certificatul de semnare este configurat și pregătit.
  </Step>
  <Step title="Salvează">
    Apasă **Salvează**. Emiterea eCMR devine activă pentru comenzile transfrontaliere.
  </Step>
</Steps>

<Note>
Majoritatea companiilor nu trebuie niciodată să schimbe asta — Nativ este singura opțiune reală. Dacă o companie are o configurare TransFollow preexistentă, aceasta continuă să funcționeze ca înainte și apare aici ca **Nativ**; migrează silențios către furnizorul nativ real la următoarea salvare a acestui card, fără nimic de schimbat sau configurat. Vezi [Furnizori eCMR](/ro/ecmr/ecmr-providers) pentru detalii.
</Note>

## 2. HERE Maps și rutare PTV

HERE Maps alimentează autocompletarea adreselor la crearea comenzilor. Calculul rutei optimizate pentru camioane, distanța, ETA și estimarea taxelor de drum sunt gestionate de **PTV**, un furnizor de rutare separat.

**Nu necesită configurare pentru niciunul.** Ambele chei API sunt gestionate la nivel de platformă de către Druma. Nu ai nimic de configurat și nu ești facturat separat pentru utilizarea HERE sau PTV — ambele sunt incluse în abonament.

<Note>
Dacă autocompletarea adreselor sau rutarea nu mai funcționează, este o problemă la nivel de platformă. Contactează suportul Druma în loc să încerci să reconfigurezi HERE sau PTV.
</Note>

## 3. Import carduri de combustibil

Druma nu se conectează direct la API-urile furnizorilor de carduri de combustibil. În schimb, exporți un CSV din portalul web al furnizorului și îl încarci în Druma. Astfel, costurile de combustibil rămân legate automat de vehicule și comenzi.

**Furnizori acceptați:** DKV, UTA, AS24, Shell, TotalEnergies, BP, Circle K, Eurowag, WEG, MOL, E100.

<Steps>
  <Step title="Exportă din portalul furnizorului">
    Autentifică-te în portalul web al furnizorului tău de card de combustibil și exportă tranzacțiile ca CSV. Majoritatea portalurilor oferă această opțiune sub **Rapoarte → Export tranzacții**.
  </Step>
  <Step title="Deschide Import Card Combustibil">
    Mergi la **Flotă → Combustibil** și deschide dialogul de import.
  </Step>
  <Step title="Alege furnizorul">
    Alege furnizorul din listă, ca Druma să știe ce format de coloane CSV să aștepte.
  </Step>
  <Step title="Încarcă CSV-ul">
    Apasă **Încarcă CSV**, selectează fișierul și apasă **Import**. Druma potrivește tranzacțiile cu vehiculele după numărul de înmatriculare.
  </Step>
</Steps>

<Note>
Dacă numărul de înmatriculare al unei tranzacții nu se potrivește cu niciun vehicul din flota ta, Druma o listează ca **nepotrivită**. O poți atribui manual sau o poți lăsa așa. Verifică periodic lista de tranzacții nepotrivite — deseori indică fraude cu cardul de combustibil sau numere de înmatriculare greșite.
</Note>

## 4. Contabilitate SAGA / WinMENTOR

Druma exportă datele de facturi și comenzi în formate compatibile cu SAGA și WinMENTOR, cele mai comune două programe românești de contabilitate.

### SAGA Classic și WinMENTOR Classic

Nu este nevoie de cheie API. SAGA exportă fișiere DBF (`CLI_`, `ART_`, `IE_`, `INT_`, `NC_.xml`); WinMENTOR Classic exportă fișiere `.txt` delimitate prin pipe. Ambele formate sunt generate automat o dată pe lună și trimise prin email ca arhivă ZIP către adresa contabilului configurată (Resend, link semnat valabil 7 zile) — configurezi ziua exportului în **Setări → Automatizări și Funcții → Configurare Export SAGA**. Nu există o listă manuală "Istoric Export" — exportul fiecărei luni există doar ca ZIP-ul trimis pe email.

<Note>
Momentan nu există o integrare API REST directă pentru WinMENTOR Enterprise sau alt program de contabilitate — SAGA și WinMENTOR Classic sunt singurele două formate acceptate, ambele bazate pe fișiere.
</Note>

## 5. SmartBill

SmartBill este o platformă românească de facturare în cloud. Cu această integrare activă, Druma trimite automat o factură către SmartBill când o **trimiți** (nu când este creată sau marcată confirmată) — fără reintroducere manuală.

<Steps>
  <Step title="Obține credențialele SmartBill">
    În contul tău SmartBill, găsește **Email-ul** de cont, **Token-ul API**, **CIF-ul** (numărul de înregistrare fiscală) și **Seria Facturii** — toate patru sunt obligatorii.
  </Step>
  <Step title="Deschide cardul SmartBill în Druma">
    Mergi la **Setări → Integrări → SmartBill**.
  </Step>
  <Step title="Introdu credențialele">
    Introdu Email-ul, Token-ul API, CIF-ul și Seria Facturii. SmartBill folosește CIF-ul pentru a direcționa facturile către contul companiei corecte.
  </Step>
  <Step title="Salvează">
    Apasă **Salvează**. Din acest moment, trimiterea unei facturi în Druma o trimite și către SmartBill.
  </Step>
</Steps>

<Note>
SmartBill atribuie propriul număr de factură la trimitere — nu reutilizează numărul de factură din Druma. Statusul este urmărit simplu ca trimis sau eroare; Druma nu urmărește starea Draft/Emisă/Plătită din SmartBill, și nu există un webhook care să mențină cele două sisteme sincronizate după trimitere (nici nu se creează înregistrări de clienți sau produse în SmartBill). Dacă abonamentul SmartBill expiră sau cheia API este regenerată, trimiterea va începe să eșueze — verifică periodic **Setări → Integrări** ca să confirmi că statusul SmartBill este verde.
</Note>

## 6. Peppol e-Facturare (Belgia)

Peppol este rețeaua paneuropeană de e-facturare. Companiile belgiene (înregistrate KBO) sunt obligate să trimită facturi către alte companii belgiene prin Peppol — aceasta este obligatorie din ianuarie 2026.

**Necesar pentru:** companiile belgiene care trimit facturi B2B către alte companii belgiene.

<Steps>
  <Step title="Găsește cardul Peppol e-Facturare">
    Mergi la **Setări → Integrări** și apasă cardul **Peppol e-Facturare**.
  </Step>
  <Step title="Introdu datele de înregistrare">
    Introdu **numărul KBO** (numărul de înregistrare al companiei belgiene) și **numărul de TVA**.
  </Step>
  <Step title="Înregistrează-te în rețeaua Peppol">
    Apasă **Înregistrează-te în Rețeaua Peppol**. Druma trimite înregistrarea către punctul de acces e-invoice.be. De regulă se finalizează în câteva minute.
  </Step>
  <Step title="Confirmă activarea">
    Odată activ, cardul arată statusul **Conectat**. Rutarea Peppol devine automată pentru clienții belgieni eligibili — nu sunt necesare pași suplimentari la trimiterea facturilor către destinatari belgieni.
  </Step>
</Steps>

<Note>
Vezi [Peppol e-Facturare](/ro/integrations/peppol-invoicing) pentru detalii complete despre cum funcționează rutarea, ce se întâmplă când un destinatar nu este în rețeaua Peppol și cum gestionezi respingerile.
</Note>

## 7. Inbox email facturi furnizori

Oferă companiei tale o adresă de email dedicată pentru primirea facturilor de la furnizori — carduri de combustibil, service, operatori de taxe de drum sau orice alt furnizor. Facturile primite sunt clasificate automat prin AI și trimise într-o coadă de revizuire, ca nimic să nu scape.

<Steps>
  <Step title="Mergi la Setările Companiei">
    Navighează la **Setări → Companie** și derulează până la secțiunea **Email Facturi Furnizori**.
  </Step>
  <Step title="Activează inbox-ul">
    Activează comutatorul **Activează inbox facturi furnizori**. Druma generează o adresă de email de intrare dedicată companiei tale.
  </Step>
  <Step title="Adaugă adresele expeditorilor în lista albă">
    În câmpul **Lista albă expeditori**, adaugă adresele de email sau domeniile de la care aștepți facturi (de exemplu, `invoices@dkv.com` sau `@uta.eu`). Email-urile de la expeditori care nu sunt în lista albă sunt respinse și nu ajung în coada ta.
  </Step>
  <Step title="Distribuie adresa furnizorilor tăi">
    Copiază adresa de email generată și dă-o fiecărui furnizor ca adresă de trimitere a facturilor pentru compania ta.
  </Step>
</Steps>

Facturile primite apar în **Finanțe → Expediție → Coada Facturi** pentru revizuire, potrivire și aprobare.

<Note>
Vezi [Facturi furnizori](/ro/invoicing/supplier-invoices) pentru detalii complete despre coada de revizuire, logica de auto-potrivire și cum gestionezi facturile nepotrivite.
</Note>

## 8. Telematică, tahograf și furnizori reefer

Druma se conectează direct la GPS-ul camioanelor, furnizorii de tahograf (ore de conducere) și reefer-ul remorcilor din **Setări → Integrări**, astfel încât pozițiile live, datele de ore de conducere conform EU 561/2006 și citirile de temperatură a mărfii ajung automat în Druma, fără introducere manuală.

### GPS și tahograf (telematică)

Deschide cardul furnizorului tău sub **Setări → Integrări** și introdu credențialele de mai jos. Link-ul "De unde obțin astea?" din fiecare card repetă acest ghidaj în aplicație.

| Furnizor | Câmpuri credențiale | De unde le obții |
|---|---|---|
| **Scania (rFMS)** | Client ID, Client Secret | Înregistrează o aplicație pe `developer.scania.com` ca să obții un Client ID și un Client Secret. Camionul are nevoie suplimentar de o unitate de bord Scania Communicator plus un abonament Location (GPS) — și, pentru orele de conducere, un abonament Performance. Autentificarea folosește schema HMAC challenge-response a Scania, gestionată automat de Druma. |
| **Volvo (rFMS)** | Utilizator, Parolă | Volvo expune același standard API rFMS ca Scania, dar cu autentificare HTTP Basic — introdu Utilizatorul și Parola emise pentru flota ta prin Volvo Connect / acces Dynafleet rFMS. |
| **Webfleet** | Cont, Utilizator, Parolă, Cheie API | De la un utilizator Webfleet cu profil "expert" și acces extern activat. Cheia API este emisă de suportul Webfleet sau prin programul de parteneri WEBFLEET.connect. |
| **Geotab** | Baza de date, Utilizator, Parolă | Creezi un Cont de Serviciu (View Only) în MyGeotab → Administration → Users. "Baza de date" este numele din URL-ul tău `my.geotab.com/<database>`. |
| **Samsara** | Token API, URL de bază (opțional) | Generează un token în dashboard-ul Samsara, sub Settings → API Tokens, cu scop "Read Vehicle Statistics". Lasă URL-ul de bază gol pentru flote UE; setează-l doar dacă organizația ta rulează pe shard-ul US. Doar poziții GPS — Samsara nu furnizează date de tahograf/ore de conducere. |
| **Frotcom** | Utilizator, Parolă, Furnizor | Credențialele contului tău Frotcom, cu acces API activat de suportul Frotcom sau distribuitorul tău local. Momentan în **beta** — conexiunea funcționează, dar maparea câmpurilor e încă în validare pe conturi live. |
| **Continental VDO** | Client ID, Secret, ID Cont/Companie | Necesită un acord de partener Continental — contactează Continental prin formularul de contact `fleet.vdo.com`. **Restricționat la parteneri** — nu există auto-înregistrare publică. |
| **Webeye / Eurowag** | Utilizator, Secret | Generate în `selfcare.eurowag.com` → Telematics → Fleet management → System connections. Compania ta trebuie să fie aprobată mai întâi ca partener de Eurowag. **Restricționat la parteneri** — nu există auto-înregistrare publică. |

<Note>
Scania este validată pe conturi de flotă live. Volvo, Webfleet, Geotab și Samsara folosesc API-urile publice standard ale furnizorilor, dar sunt încă în validare cu flote pilot — le poți configura singur, iar la prima sincronizare recomandăm implicarea suportului Druma pentru confirmarea mapării câmpurilor pe contul tău. Frotcom este în beta — funcționează, dar maparea câmpurilor sale este încă în confirmare. Continental VDO și Webeye/Eurowag necesită ca furnizorul să aprobe compania ta ca partener înainte ca legătura să returneze date live; formularul de credențiale îți permite oricum să salvezi și să testezi, dar sincronizarea nu începe până când acel acces de partener este activ.
</Note>

### Temperatura reefer / remorcă

<Steps>
  <Step title="Deschide cardul furnizorului reefer">
    În **Setări → Integrări**, găsește cardul furnizorului de telematică al remorcii tale — **Mapon**, **Orbcomm**, **Thermo King TracKing** sau **Carrier Lynx Fleet** — și deschide-l.
  </Step>
  <Step title="Introdu credențialele">
    Link-ul "De unde obțin astea?" din fiecare card explică cum obții credențialele pentru acel furnizor (vezi tabelul de mai jos).
  </Step>
  <Step title="Testează și salvează">
    Apasă **Testează Conexiunea**, apoi **Salvează**. Citirile de temperatură încep să se sincronizeze automat odată ce conexiunea este confirmată.
  </Step>
</Steps>

| Furnizor | Câmpuri credențiale | De unde le obții |
|---|---|---|
| **Mapon** | Cheie API, URL de bază (opțional) | Generează o cheie API în platforma Mapon, sub Settings → API. API complet public — credențialele se conectează imediat. |
| **Orbcomm** | Token de acces, sau Utilizator + Parolă, URL de bază (opțional) | Emis prin contul tău ORBCOMM Platform API. Dacă ai doar utilizator/parolă, Druma le schimbă automat pentru un token. |
| **Thermo King TracKing** | Cheie API, sau Utilizator + Parolă, URL de bază (opțional) | Solicită o cheie API TracKing de la dealerul tău Thermo King sau prin portalul TracKing. Fără auto-înregistrare publică — este o integrare restricționată la parteneri. |
| **Carrier Lynx Fleet** | Client ID + Client Secret (sau o Cheie API veche), URL de bază (opțional) | Obținute prin Carrier Transicold sau dealerul tău Carrier, ca parte din setul de instrumente API Lynx Fleet. Fără auto-înregistrare publică. |

<Note>
Toți cei patru conectori reefer sunt momentan în **beta** — sunt în validare cu flote pilot, așa că implică suportul Druma la prima sincronizare. API-ul Mapon este complet public, deci credențialele se conectează imediat. Orbcomm are nevoie de un token de cont de la ORBCOMM înainte să returneze date live. Thermo King TracKing și Carrier Lynx Fleet sunt doar pentru parteneri — trebuie să soliciți acces API de la furnizor înainte ca Druma să poată prelua date live, chiar dacă formularul de conexiune este disponibil pentru toți patru.
</Note>
