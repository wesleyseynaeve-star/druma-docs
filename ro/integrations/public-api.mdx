API-ul Public Druma îți oferă acces REST **doar-citire** la comenzile tale — util pentru un portal de self-service pentru clienți, un instrument BI/de raportare, sau instrumente interne construite de echipa ta.

---

## Chei API și domenii

Administratorii firmei își emit propriile chei din **Setări → Integrări → Chei API** — apasă **Creează cheie**, dă-i un nume (de exemplu `Export QuickBooks`) și alege un domeniu:

| Domeniu | Ce permite |
|---|---|
| **Operator (acces complet de citire)** | Endpoint-urile doar-citire de pe această pagină, pentru propria firmă |
| **Finance (export facturabil + preluare facturi)** | Doar [Finance API](/ro/integrations/finance-api) — preluarea comenzilor facturabile și înregistrarea facturilor emise |
| **Accountant (citire pe mai multe firme)** | Acces de citire pentru firmele pentru care este emisă cheia |

<Warning>
Cheia completă este afișată **o singură dată**, în momentul creării. Druma reține doar un hash, deci nu o mai poate afișa niciodată — copiaz-o imediat în sistemul de destinație. Dacă o pierzi, revocă cheia și emite alta.
</Warning>

Cheile existente își afișează domeniul, un prefix și data ultimei utilizări (sau **niciodată**). **Revocă** scoate o cheie din uz imediat — orice sistem care încă o folosește se oprește pe loc, așa că verifică *Ultima utilizare* înainte de a revoca una pe care nu ai emis-o tu.

Un domeniu nu este o sugestie: apelarea unui endpoint Finance API cu o cheie Operator eșuează cu `403`, și invers.

## Autentificare

Toate cererile API trebuie să includă cheia ta API în header-ul `X-API-Key`:

```
X-API-Key: CHEIA_TA_API
```

Cererile fără o cheie validă returnează un răspuns `401 Unauthorized`. Autentificarea prin token Bearer (`Authorization: Bearer ...`) **nu** este acceptată și returnează de asemenea 401.

## Endpoint-uri disponibile

API-ul public este doar-citire — sunt acceptate doar cererile `GET`. Toate răspunsurile sunt JSON. (Scrierea înapoi în Druma este sarcina [Finance API](/ro/integrations/finance-api), cu cheie proprie.)

| Metodă | Endpoint | Descriere |
|---|---|---|
| `GET` | `/orders` | Lista comenzilor (paginată, filtru opțional `status`) |
| `GET` | `/orders/{id}` | Detaliul comenzii |
| `GET` | `/orders/{id}/location` | Poziția curentă a camionului și cel mai recent ETA |
| `GET` | `/orders/{id}/documents` | Lista de documente, cu URL-uri de descărcare semnate, cu timp limitat |

Orice altă resursă, sau orice metodă non-GET, returnează o eroare `404`/`405`.

## Limite de rată

- **100 de cereri pe minut** per cheie API
- Dacă depășești limita, primești un răspuns `429 Too Many Requests`, cu un header `Retry-After` care îți spune câte secunde să aștepți
- Nu sunt returnate alte header-e de limită de rată

Pentru limite mai mari, contactează support@druma.io cu cazul tău de utilizare.
