Druma rulează un server **MCP (Model Context Protocol)** la distanță, ca să poți conecta propriul tău client AI — Claude Code, Claude Desktop, GitHub Copilot (mod agent), OpenAI Codex CLI, Gemini CLI sau Cursor — direct la datele tale Druma. Întreabă-l despre comenzile, flota, șoferii și facturile tale în limbaj natural și — cu un domeniu opțional (opt-in) — lasă-l să **propună** atribuiri de camioane pe care le aprobi tu.

<Warning>
Conectorul MCP este o funcție controlată printr-un feature-flag și este dezactivat implicit. Contactează **support@druma.io** ca să îl activezi pentru contul tău.
</Warning>

## Cum rămâne sigur

- **Tot ce poate vedea AI-ul respectă rolul și compania ta** — are acces doar la ce ai deja acces în Druma. Nu există nicio modalitate ca el să citească datele altei companii.
- **Nu poate schimba nimic de la sine.** Singura acțiune pe care o poate face este să **propună** o atribuire de camion; nimic nu se aplică până nu confirmi explicit. Nu există acțiuni de ștergere, în masă sau de bază de date în format liber.
- **Token-ul tău este secret.** Druma stochează doar un hash unidirecțional al lui — token-ul complet este afișat o singură dată, la creare, și niciodată din nou.
- Fiecare cerere este limitată ca rată și înregistrată pentru administratorii tăi.

## 1. Creează un token de acces personal

1. Mergi la **Setări → IA conectată (MCP)**.
2. Sub **Creează token**, dă-i un nume (de ex. "Claude Code — laptop").
3. Alege **domeniile**:
   - `read` (mereu activ) — citește comenzi, flotă, șoferi, facturi și KPI-uri.
   - `write:planning` (opțional) — permite în plus AI-ului să **propună** atribuiri de camioane. Chiar și cu asta activat, nimic nu se aplică fără confirmarea ta explicită.
4. Alege o expirare (30 / 90 / 365 zile) și apasă **Creează token**.
5. **Copiază token-ul acum** — este afișat o singură dată. Arată cam așa: `druma_pat_…`.

Poți revoca orice token oricând din același ecran; administratorii companiei pot revoca orice token din companie.

## 2. URL-ul serverului tău

```
https://<your-project>.supabase.co/functions/v1/mcp-server
```

URL-ul exact pentru contul tău este afișat pe pagina **Setări → IA conectată (MCP)**, cu un buton de copiere.

## 3. Conectează-ți clientul

Înlocuiește `<url>` cu URL-ul serverului tău și `<token>` cu token-ul tău de acces personal.

<Tabs>
  <Tab title="Claude Code">
```bash
claude mcp add --transport http druma <url> --header "Authorization: Bearer <token>"
```
  </Tab>
  <Tab title="VS Code (Copilot)">
Creează `.vscode/mcp.json`. Folosirea unui `input` păstrează token-ul în afara fișierului comis:
```json
{
  "servers": {
    "druma": {
      "type": "http",
      "url": "<url>",
      "headers": { "Authorization": "Bearer ${input:druma_token}" }
    }
  },
  "inputs": [
    { "id": "druma_token", "type": "promptString", "description": "Druma token", "password": true }
  ]
}
```
  </Tab>
  <Tab title="Codex CLI">
Adaugă în `~/.codex/config.toml`:
```toml
[mcp_servers.druma]
url = "<url>"
http_headers = { Authorization = "Bearer <token>" }
```
  </Tab>
  <Tab title="Gemini CLI">
Adaugă în `~/.gemini/settings.json`:
```json
{
  "mcpServers": {
    "druma": { "httpUrl": "<url>", "headers": { "Authorization": "Bearer <token>" } }
  }
}
```
  </Tab>
  <Tab title="Cursor">
Adaugă în `~/.cursor/mcp.json`:
```json
{
  "mcpServers": {
    "druma": { "url": "<url>", "headers": { "Authorization": "Bearer <token>" } }
  }
}
```
  </Tab>
</Tabs>

## 4. Ce poți întreba

- "Ce comenzi sunt neatribuite pentru mâine?"
- "Arată-mi comenzile întârziate din această săptămână și ce camioane sunt libere."
- "Care e totalul meu de creanțe restante, pe client?"
- Cu `write:planning`: "Propune camionul RO-123-ABC pentru comanda 4021." — AI-ul creează o propunere și îți arată un rezumat; îi spui apoi să confirme, și abia atunci atribuirea este aplicată.

## Conectori de chat web (ChatGPT, claude.ai)

Conectarea aplicațiilor de chat **web** de pe chatgpt.com sau claude.ai (în loc de un client desktop/CLI) necesită OAuth și **va veni mai târziu**. Deocamdată, folosește unul dintre clienții de mai sus.

## Rotirea token-ului

Preferă token-uri cu durată scurtă de viață. Pentru a rota: creează un token nou, actualizează configurația clientului tău, apoi revocă-l pe cel vechi. Revocă orice token al cărui "Ultima utilizare" este gol — înseamnă că nimic nu s-a conectat vreodată cu el.

## Vezi și

Dacă preferi să discuți cu un AI **în interiorul** Druma (folosind propria ta cheie Anthropic, OpenAI sau Gemini) în loc să conectezi un client extern, vezi [Druma Copilot](/ro/integrations/copilot).
