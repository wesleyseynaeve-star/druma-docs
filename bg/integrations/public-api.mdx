Публичният API на Druma дава **достъп само за четене** (REST) до вашите поръчки — подходящ за портал за самообслужване на клиенти, BI/отчетен инструмент или вътрешни инструменти.

---

## API ключове и обхвати

Администраторите на фирмата издават собствени ключове от **Настройки → Интеграции → API ключове** — натиснете **Създай ключ**, дайте му име и изберете обхват:

| Обхват | Какво дава |
|---|---|
| **Operator (пълен достъп за четене)** | Крайните точки само за четене от тази страница, за вашата фирма |
| **Finance (експорт за фактуриране + внасяне на фактури)** | Само [Finance API](/bg/integrations/finance-api) |
| **Accountant (четене за няколко фирми)** | Достъп за четене до фирмите, за които е издаден ключът |

<Warning>
Пълният ключ се показва **само веднъж**, при създаването. Druma пази само хеш, така че не може да го покаже отново — копирайте го веднага. Ако го загубите, отменете ключа и издайте нов.
</Warning>

Обхватът не е препоръка: извикване на крайна точка на Finance API с ключ Operator връща `403` — и обратно.

## Автентикация

Всички заявки трябва да съдържат вашия API ключ в хедъра `X-API-Key`:

```
X-API-Key: YOUR_API_KEY
```

Заявки без валиден ключ връщат `401 Unauthorized`. Автентикация с Bearer токен (`Authorization: Bearer ...`) **не** се поддържа и също връща 401.

Базов URL: `https://iyegqyqnihupmhmrxfnx.supabase.co/functions/v1/public-api`

## Налични крайни точки

Публичният API е само за четене — приемат се само заявки `GET`. Всички отговори са JSON.

| Метод | Крайна точка | Описание |
|---|---|---|
| `GET` | `/orders` | Списък с поръчки (странициран, незадължителен филтър `status`) |
| `GET` | `/orders/{id}` | Детайли на поръчка |
| `GET` | `/orders/{id}/location` | Текуща позиция на камиона и последно ETA |
| `GET` | `/orders/{id}/documents` | Документи с подписани URL адреси за изтегляне |
| `GET` | `/pallet-balances` | Палетна позиция по клиент и превозвач (само ключове Operator) |
| `GET` | `/pallet-movements` | Палетен регистър, странициран (само ключове Operator) |
| `GET` | `/pallet-vouchers/{id}` | Подписан палетен ваучер (само ключове Operator) |
| `GET` | `/jpk-v7m` | Полски ДДС записи за един месец като XML файл |

Всеки друг ресурс или метод, различен от GET, връща грешка `404`/`405`. Страницирането използва `?page=` и `?limit=` (макс. 100).

Това API е **v1**: пътищата работят и като `/public-api/v1/...`, а всеки отговор съдържа хедър `Druma-Api-Version`. Нови полета могат да се появят по всяко време, затова игнорирайте непознатите. Вижте [Версиониране на API](/bg/integrations/api-versioning). Пълният справочник OpenAPI е в навигацията в групата **API reference**.

## Ограничения на заявките

- **100 заявки в минута** на API ключ
- Ако превишите лимита, получавате `429 Too Many Requests` с хедър `Retry-After`, който показва колко секунди да изчакате

За по-високи лимити пишете на support@druma.io.
