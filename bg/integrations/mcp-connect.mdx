Druma управлява отдалечен сървър **MCP (Model Context Protocol)**, така че можете да свържете собствения си AI клиент — Claude Code, Claude Desktop, GitHub Copilot (агентен режим), OpenAI Codex CLI, Gemini CLI, или Cursor — директно към данните си в Druma. Питайте го за поръчките, автопарка, шофьорите и фактурите си на естествен език, и — с незадължителен обхват — оставете го да **предлага** възлагания на камиони, които вие одобрявате.

<Warning>
Конекторът MCP е функция, управлявана от флаг за функция, и по подразбиране е изключен. Свържете се с **support@druma.io**, за да го активирате за акаунта си.
</Warning>

## Как остава безопасно

- **Всичко, което AI може да види, зачита вашата роля и компания** — той винаги има само достъпа, който вече имате в Druma. Няма начин той да чете данни на друга компания.
- **Не може да променя нищо сам.** Единственото действие, което може да предприеме, е *предлагането* на възлагане на камион; нищо не се прилага, докато изрично не го потвърдите. Няма действия за изтриване, масови, или в свободен формат върху базата данни.
- **Вашият токен е тайна.** Druma съхранява само еднопосочен хеш от него — пълният токен се показва веднъж, при създаването, и никога повече.
- Всяка заявка е ограничена по скорост и записана за вашите администратори.

## 1. Създайте личен токен за достъп

1. Отидете на **Настройки → Интеграции → Свързан AI (MCP)**.
2. Под **Създай токен**, дайте му име (напр. „Claude Code — лаптоп").
3. Изберете **обхватите**:
   - `read` (винаги включен) — четене на поръчки, автопарк, шофьори, фактури и KPI.
   - `write:planning` (по избор) — допълнително позволете на AI да *предлага* възлагания на камиони. Дори и с това включено, нищо не се прилага без вашето изрично потвърждение.
4. Изберете срок на валидност (30 / 90 / 365 дни) и кликнете върху **Създай токен**.
5. **Копирайте токена сега** — показва се само веднъж. Изглежда като `druma_pat_…`.

Можете да отмените всеки токен по всяко време от същия екран; администраторите на компанията могат да отменят всеки токен в компанията.

## 2. URL адресът на вашия сървър

```
https://<вашия-проект>.supabase.co/functions/v1/mcp-server
```

Точният URL адрес за вашия акаунт се показва на страницата **Настройки → Интеграции → Свързан AI (MCP)** с бутон за копиране.

## 3. Свържете вашия клиент

Заменете `<url>` с URL адреса на вашия сървър и `<token>` с вашия личен токен за достъп.

<Tabs>
  <Tab title="Claude Code">
```bash
claude mcp add --transport http druma <url> --header "Authorization: Bearer <token>"
```
  </Tab>
  <Tab title="VS Code (Copilot)">
Създайте `.vscode/mcp.json`. Използването на `input` държи токена извън комитнатия файл:
```json
{
  "servers": {
    "druma": {
      "type": "http",
      "url": "<url>",
      "headers": { "Authorization": "Bearer ${input:druma_token}" }
    }
  },
  "inputs": [
    { "id": "druma_token", "type": "promptString", "description": "Druma токен", "password": true }
  ]
}
```
  </Tab>
  <Tab title="Codex CLI">
Добавете към `~/.codex/config.toml`:
```toml
[mcp_servers.druma]
url = "<url>"
http_headers = { Authorization = "Bearer <token>" }
```
  </Tab>
  <Tab title="Gemini CLI">
Добавете към `~/.gemini/settings.json`:
```json
{
  "mcpServers": {
    "druma": { "httpUrl": "<url>", "headers": { "Authorization": "Bearer <token>" } }
  }
}
```
  </Tab>
  <Tab title="Cursor">
Добавете към `~/.cursor/mcp.json`:
```json
{
  "mcpServers": {
    "druma": { "url": "<url>", "headers": { "Authorization": "Bearer <token>" } }
  }
}
```
  </Tab>
</Tabs>

## 4. Какво можете да питате

- „Кои поръчки за утре все още нямат камион?"
- „Покажи ми закъснелите поръчки тази седмица и кои камиони са свободни."
- „Каква е общата сума на просрочените ми вземания по клиент?"
- С `write:planning`: „Предложи камион RO-123-ABC за поръчка 4021." — AI създава предложение и ви показва обобщение; след това му казвате да потвърди, и едва тогава се прилага възлагането.

## Уеб чат конектори (ChatGPT, claude.ai)

Свързването на **уеб** чат приложенията на chatgpt.com или claude.ai (вместо десктоп/CLI клиент) изисква OAuth и **идва по-късно**. Засега използвайте един от клиентите по-горе.

## Ротация на токени

Предпочитайте краткотрайни токени. За ротация: създайте нов токен, актуализирайте конфигурацията на клиента си, след което отменете стария. Отменяйте всеки токен, чието поле „Последно използван" е празно — това означава, че никога нищо не се е свързало с него.

## Свързано

Ако предпочитате да чатите с AI **вътре** в Druma (използвайки собствен ключ за OpenAI, Anthropic, или Gemini) вместо да свързвате външен клиент, вижте [Druma Copilot](/bg/integrations/copilot).
