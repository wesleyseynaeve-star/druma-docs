## Überblick

Die Aufgaben-Engine hängt eine **Checkliste** an einen Auftrag (oder eine Rechnung), die die von Ihrem Unternehmen geforderten Schritte in jeder Phase verfolgt — eine Bestätigung senden, ein Dokument erstellen, bei einem Kunden nachfassen — und zeigt, wer verantwortlich ist und ob etwas überfällig ist. Admins bauen die Checkliste einmal als wiederverwendbare **Aufgabenvorlage**; von da an materialisiert sie sich automatisch auf jedem passenden Auftrag.

Diese Seite behandelt beide Seiten: was ein Planer oder Disponent im Alltag sieht, und wie ein Admin die dahinterliegenden Vorlagen konfiguriert.

---

## Was Sie an einem Auftrag sehen

Öffnen Sie einen beliebigen Auftrag (oder eine Rechnung) mit einer passenden Aufgabenvorlage, und Sie finden ein **Aufgaben-Checklisten**-Panel, das jeden erforderlichen Schritt für die aktuelle Phase zeigt.

Jede Zeile zeigt:

- Ein Statussymbol — ausstehend (leerer Kreis), in Bearbeitung (Uhr), erledigt (Häkchen), übersprungen, oder fehlgeschlagen
- Die verantwortliche Rolle, falls eine gesetzt ist
- **Wartet auf einen vorherigen Schritt**, wenn die Aufgabe von einem anderen, noch nicht erledigten Schritt abhängt
- Ein **Fällig**- oder **Überfällig**-Abzeichen, wenn der Schritt ein Fälligkeitsdatum hat

Bei offenen Schritten können Sie:
- Auf das Häkchen-Symbol klicken, um ihn **als erledigt zu markieren**
- Auf das Überspringen-Symbol klicken, um ihn **zu überspringen** (optional mit einem Grund)

Beide Aktionen sind deaktiviert, solange der Schritt durch eine Abhängigkeit blockiert ist. Ist ein Schritt so konfiguriert, dass er sich automatisch abschließt oder überspringt, sobald der Auftrag einen bestimmten Status erreicht, sehen Sie einfach, wie er sich von selbst auf Erledigt oder Übersprungen umschaltet — kein Klick nötig.

Auftrags- und Rechnungslistenzeilen tragen auch einen kleinen Zusammenfassungs-Chip: ein gelbes Zählabzeichen, solange Aufgaben noch ausstehen, oder ein grünes **alles erledigt**-Häkchen, sobald jede Aufgabe auf diesem Datensatz abgeschlossen ist. Passt keine Vorlage zur aktuellen Phase eines Auftrags, liest das Panel einfach *„Für diese Phase ist keine Aufgaben-Checkliste konfiguriert."*

<Note>
Aufgaben sind an die **Lebenszyklusphase** gebunden — dieselben Status, die in [Auftragslebenszyklus](/de/planner/order-lifecycle) behandelt werden. Eine Checkliste erscheint (oder aktualisiert sich) automatisch, sobald der Auftrag oder die Rechnung eine Phase erreicht, auf die eine Vorlage zielt.
</Note>

## Wie Admins Aufgabenvorlagen konfigurieren

Gehen Sie zu **Einstellungen → Vorlagen & Zonen → Aufgabenvorlagen**. Vorlagen werden für jedes Unternehmen leer ausgeliefert — nichts ist vorkonfiguriert, sodass der Aufbau Ihrer Checkliste vollständig optional ist.

<Steps>
  <Step title="Eine Vorlage erstellen">
    Klicken Sie auf **Vorlage hinzufügen**. Wählen Sie den **Objekttyp** (Auftrag oder Rechnung), die **Lebenszyklusphase**, bei der er auslösen soll (z. B. Bestätigt, Zugestellt), und ein Label. Lassen Sie sie aktiviert, damit sie sofort live ist, oder speichern Sie sie deaktiviert, während Sie sie ausbauen.
  </Step>
  <Step title="Optional mit Bedingungen eingrenzen">
    Verwenden Sie **Gilt, wenn**, um die Vorlage nur auf passende Aufträge zu beschränken — zum Beispiel nur ADR-Ladungen, nur einen bestimmten Kunden, oder nur Kabotage-Bewegungen. Lassen Sie es leer, und die Vorlage gilt für jeden Auftrag, der die Zielphase erreicht.
  </Step>
  <Step title="Schritte hinzufügen">
    Legen Sie für jeden Schritt einen Schritt-Schlüssel und ein Label fest, dann einen **Schritttyp**:
    - **Manuell** — eine Person muss ihn selbst als erledigt markieren oder überspringen
    - **Dokument erstellen**, **E-Mail senden**, oder **Automatisierung ausführen** — wählen Sie eine bestimmte Aktion aus der kuratierten Liste (z. B. Rechnung erstellen, Auftragsbestätigung senden, CMR erstellen)
  </Step>
  <Step title="Abschlussmodus festlegen">
    Wählen Sie **Manuell** (jemand schließt ihn über die Checkliste ab) oder **Auto** — ein automatischer Schritt schließt sich selbst ab oder überspringt sich, sobald der Auftrag/die Rechnung einen von Ihnen konfigurierten Status erreicht, ohne dass jemand klicken muss.
  </Step>
  <Step title="Verantwortung und Reihenfolge hinzufügen">
    Legen Sie optional eine **verantwortliche Rolle** fest, machen Sie den Schritt **abhängig von** einem früheren Schritt (er bleibt blockiert, bis dieser erledigt ist), und legen Sie seine Position in der Checkliste fest.
  </Step>
  <Step title="Speichern">
    Die Vorlage materialisiert nun eine Checkliste auf jedem Auftrag (oder jeder Rechnung), der/die zu ihrem Objekttyp, ihrer Phase, und ihren Bedingungen passt.
  </Step>
</Steps>

## Überschreibungen pro Kunde

Manche Kunden brauchen eine andere Checkliste als der Rest Ihres Portfolios — einen zusätzlichen Dokumentschritt, oder einen, den sie ausdrücklich nicht brauchen. Statt eine ganz separate Vorlage zu bauen, überschreiben Sie sie pro Kunde.

Öffnen Sie die Detailseite des Kunden und gehen Sie zum Tab **Aufgabenüberschreibungen**. Dort können Sie deaktivieren:
- Eine ganze Vorlage, nur für diesen Kunden, oder
- Einzelne Schritte innerhalb einer Vorlage

Die unternehmensweite Vorlage bleibt für jeden anderen Kunden unberührt — die Überschreibung betrifft nur den einen Kundendatensatz, den Sie bearbeiten.

---

## Hinter den Kulissen

Ein geplanter Job prüft alle paar Minuten auf Aufgaben, die bereit zur Ausführung sind — Abhängigkeiten erfüllt, fällig, und für Auto-Ausführung konfiguriert — und löst sie aus, ohne dass jemand die Checkliste öffnen muss. Dies ist rein ein Zuverlässigkeitsdetail; im Alltag interagieren Sie nur mit dem Checklisten-Panel am Auftrag selbst.
