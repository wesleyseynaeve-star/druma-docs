Jeder Frachtführer verfolgt etwas, wofür Druma kein Feld hat: eine interne Referenznummer, den eigenen Buchungscode eines Kunden, zu welchem Depot ein LKW gehört, die Ausweisnummer eines Fahrers. Benutzerdefinierte Felder lassen Sie diese hinzufügen, ohne auf eine Produktänderung zu warten.

Sie finden dies unter **Einstellungen → Unternehmen**, im Abschnitt **Benutzerdefinierte Felder**, und es erfordert die Rolle Admin oder Unternehmensadmin. Ohne sie sehen Sie *„Sie benötigen die Rolle Admin oder Unternehmensadmin, um Unternehmenseinstellungen zu bearbeiten."*

---

## Vier Entitäten, separate Feldsätze

Benutzerdefinierte Felder werden pro Entität definiert, auf ihrem eigenen Tab:

- **Auftrag**
- **LKW**
- **Fahrer**
- **Kunde**

Jede Entität behält ihren eigenen unabhängigen Satz — ein zu LKW hinzugefügtes Feld erscheint nicht bei Fahrern.

<Warning>
Es gibt eine feste Grenze von **30 aktiven Feldern pro Entität**. Sobald diese erreicht ist, wird die Schaltfläche **Feld hinzufügen** durch *„Feldlimit erreicht — max. 30 aktive Felder pro Entität"* ersetzt. Dies ist eine bewusste Obergrenze: Jenseits davon hört eine Detailseite auf, lesbar zu sein, und ein Listenexport hört auf, brauchbar zu sein.
</Warning>

---

## Ein Feld hinzufügen

<Steps>
  <Step title="Den Entitäts-Tab wählen">
    Auftrag, LKW, Fahrer oder Kunde.
  </Step>
  <Step title="Auf Feld hinzufügen klicken">
    Füllen Sie das **Feldlabel** aus — was Benutzer sehen, z. B. `Interne Referenz`.
  </Step>
  <Step title="Einen Typ wählen">
    | Typ | Verwenden Sie es für |
    |---|---|
    | **Text** | Kurzer Freitext — eine Referenz, ein Code |
    | **Langer Text** | Notizen und mehrzeilige Bemerkungen |
    | **Zahl** | Mengen, Zählungen, numerische Codes |
    | **Datum** | Ein Datum, das die Standardfelder nicht abdecken |
    | **Auswahl** | Eine feste Liste von Optionen |
    | **Checkbox** | Ein Ja/Nein-Kennzeichen |
  </Step>
  <Step title="Einen Feldschlüssel festlegen">
    Der interne Bezeichner, der in Exporten und Integrationen verwendet wird. Sowohl Label als auch Schlüssel sind erforderlich.
  </Step>
  <Step title="Für ein Auswahlfeld die Optionen auflisten">
    Geben Sie diese kommagetrennt ein — z. B. `Nord, Süd`. Ein Dropdown ohne Optionen kann nicht gespeichert werden: Druma verweigert mit *„Fügen Sie mindestens eine Option für ein Dropdown-Feld hinzu"*.
  </Step>
  <Step title="Entscheiden Sie, ob es Pflicht ist">
    Ein Pflichtfeld muss ausgefüllt werden, bevor der Datensatz gespeichert werden kann.
  </Step>
  <Step title="Speichern">
    Das Feld erscheint sofort auf den Detailseiten dieser Entität.
  </Step>
</Steps>

---

## Reihenfolge und Bearbeitung

Felder werden in der Reihenfolge dargestellt, in der sie aufgelistet sind. **Nach oben** und **Nach unten** ordnen sie neu — platzieren Sie die am häufigsten ausgefüllten oben.

**Optionen bearbeiten** ändert die Auswahlmöglichkeiten eines Auswahlfelds, **Pflichtfeld** schaltet die Anforderung um, und **Feld löschen** entfernt es.

---

## Wo benutzerdefinierte Felder erscheinen

- **Detailseiten** — auf einem Tab des Auftrags-, LKW-, Fahrer- oder Kundendatensatzes
- **Listenspalten** — opt-in, pro Liste. Sie werden nicht standardmäßig angezeigt, sodass ein Unternehmen mit 30 LKW-Feldern keine unbrauchbare LKW-Tabelle erhält
- **Exporte** — die Spalten, für die Sie sich entschieden haben, werden im Export mitgeliefert
