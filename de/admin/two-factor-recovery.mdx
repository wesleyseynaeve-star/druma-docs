## Einen zweiten Authenticator hinzufügen

Öffnen Sie **Einstellungen → Sicherheit**. Jeder Ihrer Authenticatoren wird mit seinem Namen aufgeführt. Wählen Sie **Weiteren Authenticator hinzufügen**, vergeben Sie einen Namen (zum Beispiel „Diensthandy“ oder „Ersatzhandy“), scannen Sie den QR-Code und bestätigen Sie mit dem 6-stelligen Code. Namen müssen eindeutig sein.

Halten Sie einen zweiten Authenticator auf einem anderen Gerät bereit. Geht ein Telefon verloren, meldet das andere Sie weiterhin an.

Solange Ihr Unternehmen die Zwei-Faktor-Authentifizierung verlangt, können Sie Ihren letzten Authenticator nicht entfernen.

## Anmeldung mit mehreren Authenticatoren

Haben Sie zwei oder mehr Authenticatoren, fragt der Anmeldebildschirm, welchen Sie verwenden möchten. Wählen Sie ihn aus und geben Sie den 6-stelligen Code dieser App ein. Haben Sie alle Authenticatoren verloren, verweist der Bildschirm Sie an einen Unternehmensadministrator (siehe unten).

## Zwei-Faktor eines Kollegen zurücksetzen

Ein Unternehmensadministrator kann einen Kollegen wiederherstellen, der seinen Authenticator verloren hat: **Einstellungen → Benutzer**, öffnen Sie die Zeilenaktionen des Kollegen, wählen Sie **Zwei-Faktor zurücksetzen** und bestätigen Sie.

**Wer das tun darf**

- Nur Benutzer mit der Berechtigung **platform:manage**, also Unternehmensadministratoren.
- Ihre eigene Sitzung muss vollständig zweifaktor-verifiziert sein. Eine Sitzung, die nur den Passwortschritt durchlaufen hat, wird abgelehnt.
- Sie können sich nicht selbst zurücksetzen.
- Sie können weder einen Plattformadministrator zurücksetzen noch einen Benutzer, der nicht Mitglied Ihres Unternehmens ist.

**Was ein Zurücksetzen bewirkt**

- Entfernt **alle** Authenticatoren des Benutzers. Das Passwort bleibt unverändert.
- Meldet ihn überall ab.
- Sendet ihm eine E-Mail, die erklärt, was geschehen ist.
- Schreibt einen Eintrag ins Audit-Protokoll.
- Bei der nächsten Anmeldung muss er einen neuen Authenticator einrichten, bevor er fortfahren kann.

<Note>Eine bereits geöffnete Sitzung kann gültig bleiben, bis ihr Zugriffstoken abläuft, etwa eine Stunde. Ein Zurücksetzen sperrt eine Person nicht sofort aus.</Note>

## Wenn der Benutzer der einzige Administrator ist

Ist der Benutzer der einzige Administrator des Unternehmens, kann ihn kein anderer Administrator zurücksetzen, weil es keinen gibt. Wenden Sie sich an den Druma-Support unter [support@druma.io](mailto:support@druma.io). Wir prüfen Ihre Identität und stellen das Konto wieder her.

## Keine Wiederherstellungscodes, mit Absicht

Druma hat keine Wiederherstellungscodes und keinen E-Mail- oder SMS-Ersatz. Ein Wiederherstellungsweg ohne zweiten Faktor wäre genau das Ziel eines Angreifers. Deshalb ist die Person, die den Benutzer kennt, sein Unternehmensadministrator, der Wiederherstellungsschritt. Fügen Sie jetzt einen zweiten Authenticator hinzu, damit Sie keine Wiederherstellung brauchen.
