## Ajouter un second authentificateur

Ouvrez **Paramètres → Sécurité**. Chacun de vos authentificateurs est listé par son nom. Choisissez **Ajouter un autre authentificateur**, donnez-lui un nom (par exemple « Téléphone pro » ou « Téléphone de secours »), scannez le QR code et confirmez avec le code à 6 chiffres. Les noms doivent être uniques.

Gardez un second authentificateur sur un autre appareil. Si un téléphone est perdu, l'autre vous connecte toujours.

Tant que votre entreprise exige la double authentification, vous ne pouvez pas supprimer votre dernier authentificateur.

## Se connecter avec plusieurs authentificateurs

Si vous avez deux authentificateurs ou plus, l'écran de connexion vous demande lequel utiliser. Choisissez-le, puis saisissez le code à 6 chiffres de cette application. Si vous les avez tous perdus, l'écran vous invite à contacter un administrateur de l'entreprise (voir ci-dessous).

## Réinitialiser la double authentification d'un collègue

Un administrateur de l'entreprise peut récupérer le compte d'un collègue qui a perdu son authentificateur : **Paramètres → Utilisateurs**, ouvrez les actions de la ligne du collègue, choisissez **Réinitialiser la double authentification** puis confirmez.

**Qui peut le faire**

- Uniquement les utilisateurs disposant de la permission **platform:manage**, c'est-à-dire les administrateurs de l'entreprise.
- Votre propre session doit être entièrement vérifiée en deux facteurs. Une session qui n'a passé que l'étape du mot de passe est refusée.
- Vous ne pouvez pas vous réinitialiser vous-même.
- Vous ne pouvez pas réinitialiser un administrateur de la plateforme ni un utilisateur qui n'est pas membre de votre entreprise.

**Ce que fait une réinitialisation**

- Supprime **tous** les authentificateurs de l'utilisateur. Son mot de passe reste inchangé.
- Le déconnecte partout.
- Lui envoie un e-mail expliquant ce qui s'est passé.
- Écrit une entrée dans le journal d'audit.
- À sa prochaine connexion, il doit configurer un nouvel authentificateur avant de continuer.

<Note>Une session déjà ouverte peut rester valide jusqu'à l'expiration de son jeton d'accès, environ une heure. Une réinitialisation ne verrouille pas immédiatement une personne.</Note>

## Quand l'utilisateur est le seul administrateur

Si l'utilisateur est le seul administrateur de l'entreprise, aucun autre administrateur ne peut le réinitialiser, car il n'y en a pas. Contactez le support Druma à [support@druma.io](mailto:support@druma.io) : nous vérifierons votre identité et récupérerons le compte.

## Pas de codes de récupération, volontairement

Druma n'a ni codes de récupération ni solution de repli par e-mail ou SMS. Une voie de récupération sans second facteur est exactement celle qu'un attaquant viserait ; l'étape de récupération est donc la personne qui connaît l'utilisateur : l'administrateur de son entreprise. Ajoutez dès maintenant un second authentificateur pour ne pas avoir besoin de récupération.
