Chaque transporteur suit quelque chose pour lequel Druma n'a pas de case : un numéro de référence interne, le propre code de réservation d'un client, à quel dépôt appartient un camion, le numéro de badge d'un chauffeur. Les champs personnalisés vous permettent de les ajouter sans attendre un changement de produit.

Vous trouverez cela dans **Paramètres → Entreprise**, dans la section **Champs personnalisés**, et cela nécessite le rôle Admin ou Admin entreprise. Sans lui, vous verrez *« Vous avez besoin du rôle Admin ou Admin entreprise pour modifier les paramètres de l'entreprise. »*

---

## Quatre entités, ensembles de champs séparés

Les champs personnalisés sont définis par entité, sur son propre onglet :

- **Commande**
- **Camion**
- **Chauffeur**
- **Client**

Chaque entité garde son propre ensemble indépendant — un champ ajouté aux camions n'apparaît pas sur les chauffeurs.

<Warning>
Il y a une limite stricte de **30 champs actifs par entité**. Une fois atteinte, le bouton **Ajouter un champ** est remplacé par *« Limite de champs atteinte — max 30 champs actifs par entité »*. C'est un plafond délibéré : au-delà, une page de détail cesse d'être lisible, et un export de liste cesse d'être utilisable.
</Warning>

## Ajouter un champ

<Steps>
  <Step title="Choisissez l'onglet entité">
    Commande, Camion, Chauffeur ou Client.
  </Step>
  <Step title="Cliquez sur Ajouter un champ">
    Remplissez le **Libellé du champ** — ce que voient les utilisateurs, par ex. `Référence interne`.
  </Step>
  <Step title="Choisissez un type">
    | Type | Utilisez-le pour |
    |---|---|
    | **Texte** | Texte libre court — une référence, un code |
    | **Texte long** | Notes et remarques multi-lignes |
    | **Nombre** | Quantités, comptages, codes numériques |
    | **Date** | Une date que les champs standard ne couvrent pas |
    | **Sélection** | Une liste fixe de choix |
    | **Case à cocher** | Un indicateur oui/non |
  </Step>
  <Step title="Définissez une clé de champ">
    L'identifiant interne utilisé dans les exports et intégrations. Le libellé et la clé sont tous deux requis.
  </Step>
  <Step title="Pour un champ Sélection, listez les options">
    Saisissez-les séparées par des virgules — par ex. `Nord, Sud`. Une liste déroulante sans options ne peut pas être enregistrée : Druma refuse avec *« Ajoutez au moins une option pour un champ liste déroulante »*.
  </Step>
  <Step title="Décidez s'il est Obligatoire">
    Un champ obligatoire doit être rempli avant que l'enregistrement puisse être sauvegardé.
  </Step>
  <Step title="Enregistrez">
    Le champ apparaît immédiatement sur les pages de détail de cette entité.
  </Step>
</Steps>

---

## Ordre et modification

Les champs s'affichent dans l'ordre où ils sont listés. **Monter** et **Descendre** les réordonnent — placez ceux que les gens remplissent le plus souvent en haut.

**Modifier les options** change les choix d'un champ Sélection, **Obligatoire** bascule l'exigence, et **Supprimer le champ** le retire.

---

## Où apparaissent les champs personnalisés

- **Pages de détail** — sur un onglet de l'enregistrement de commande, camion, chauffeur ou client
- **Colonnes de liste** — optionnel, par liste. Ils ne sont pas affichés par défaut, donc une entreprise avec 30 champs camion n'obtient pas un tableau de camions inutilisable
- **Exports** — les colonnes que vous avez choisies accompagnent l'export
