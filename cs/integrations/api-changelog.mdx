Změny uvnitř v1 jsou aditivní. Zásadní změny a vyřazení se uvádějí nejdříve zde. Pravidla popisuje [Verzování API](/cs/integrations/api-versioning).

## 2026-10-10

**Přidáno (v1, není třeba nic dělat)**

- **Hlavičky verze.** Každá odpověď Veřejného API, Finance API a příchozího Client API obsahuje `Druma-Api-Version: 1`. Můžete ji posílat i v požadavcích.
- **Cesty `/v1/`.** `/public-api/v1/orders` a `/finance-api/v1/billable` nyní fungují. Stávající cesty bez verze zůstávají beze změny a znamenají v1.
- **`event_id` a `api_version` ve webhookách.** Tělo každého webhooku získává tato dvě pole. `event_id` je při opakováních stabilní, použijte ho k deduplikaci.
- **Hlavičky webhooků.** `X-Druma-Event-Id`, `X-Druma-Event-Type`, `X-Druma-Timestamp` a `Druma-Api-Version` u každého doručení.
- **Podpis s časovým razítkem.** Doručení HMAC přidávají `X-Druma-Signature-V2: t=<unix>,v1=<hex>` jako ochranu proti přehrání. `X-Druma-Signature` je beze změny.
- **Reference OpenAPI 3.1** pro Veřejné API a Finance API.

**Vyřazeno / odstraněno:** nic.
